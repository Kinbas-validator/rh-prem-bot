Установка и обновление RWA Premium Monitor на Ubuntu VPS через GitHub.

- Загрузка готового установщика и проверка SHA256.
- Обновление командой `sudo rh-prem-bot update` с сохранением настроек и базы.
- Автоматический откат при ошибке запуска.
- Изолированные Python и зависимости; установщик не вызывает APT, не заменяет системный Python и не управляет Docker или другими сервисами.
- Ограничения по умолчанию для службы: CPU 50% одного ядра, память 256 МиБ, swap 64 МиБ, 64 задачи и пониженный приоритет.
- Сохраняются текущая и предыдущая версии программы; более старые версии очищаются после успешной установки.

Все тесты приложения и установщика выполняются в GitHub Actions перед публикацией релиза. Исходные пользовательские изображения, токены Telegram, базы и локальные настройки в релиз не включаются.
