## Установщик Ubuntu VPS, версия 1.1.0

Команда установки: `sudo bash rh-prem-bot-installer.run`. Исходный скрипт — `install.sh`; сборщик единого самораспаковывающегося файла — `scripts/build_installer.py`.

- Полный набор: **128 passed**. Bash-синтаксис, Ruff и ShellCheck — успешно.
- Интеграционные тесты выполняют настоящий Bash-скрипт в изолированных временных каталогах. Проверены первая установка, динамические пути сервиса, права файлов, команды управления, обновление с сохранением конфигурации/SQLite, сброс Telegram-порогов при повторной настройке, ошибка предварительной диагностики и ошибка старта новой версии.
- Проверены откат исполняемой версии, service-файла, конфигурации, базы и автозапуска; блокировка преждевременного успеха по статусу старого PID. Если systemd не смог остановить процесс для отката, установщик сохраняет резервные файлы и не перезаписывает работающую базу.
- Самораспаковывающийся файл проверен: Bash-синтаксис/справка, декодирование и целостность tar.gz, соответствие текущему исходному коду, отсутствие токенов, `.env`, баз и небезопасных путей в payload.
- Привилегированные APT/systemd/useradd/chown в интеграционных тестах заменены имитациями; тесты не устанавливают настоящий сервис в рабочую среду.
- Отдельно **реально выполнена загрузка официального uv 0.13.4, управляемого CPython 3.12.15 и зависимостей по uv.lock** в изолированный каталог `/tmp`, без изменения системного Python. Установленный пакет 1.1.0 успешно выполнил `demo` и `doctor`: настоящие REST и WebSocket Lighter подтвердили 34 выбранных RWA-рынка. Системный APT на этом этапе не вызывался.
- Сгенерированный файл systemd успешно проверен `systemd-analyze verify`. Установка на отдельный VPS с настоящим созданием пользователя и запуском системной службы не выполнялась; это произойдёт при запуске установщика пользователем.

Инструкция: [INSTALLATION.md](INSTALLATION.md). При обычном обновлении настройки `/set` и база сохраняются. Повторная настройка запрашивает параметры заново и сбрасывает сохранённые пороги, чтобы новые значения сразу применились.
